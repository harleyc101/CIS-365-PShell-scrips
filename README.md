# CIS-365-PShell-scrips

PowerShell scripts for auditing a Microsoft 365 tenant against the CIS Microsoft 365 Foundations Benchmark.

Each script lives on its own branch. The branch's README explains why the control is required, what the script does, and how to read the results.
